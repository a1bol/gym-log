# Дневник тренировок и питания — Telegram Mini App

Статичное мини-приложение без сервера. Данные хранятся в **Telegram CloudStorage**: они привязаны к твоему аккаунту и боту и синхронизируются между телефоном и десктопом. В репозитории лежит только код, твоих данных в нём нет.

## Что умеет
- **Тренировка**: упражнения и подходы (повторы × вес), кнопки ±1 повтор / ±2.5 кг, добавление N одинаковых подходов сразу, подсказка «прошлый раз», заметки (читинг, на пределе…), повтор упражнений из прошлой тренировки, ввод текстом в формате `Жим лежа - 4х8 25кг`.
- **Питание**: КБЖУ на 100 г × граммы или сразу «всего», приёмы пищи, прогресс к цели за день, список «мои продукты» для быстрого добавления.
- **История**: все тренировки текстом, график прогресса по упражнению (макс. вес, оценка 1ПМ, объём, повторы), калории и белок за 14 дней.
- **Ещё**: цели КБЖУ, импорт старых записей из «Избранного», экспорт текстом, JSON-бэкап и восстановление.

## Запуск
1. **Хостинг.** GitHub → репозиторий → Settings → Pages → Source: *Deploy from a branch*, Branch: `main` / `(root)` → Save. Через минуту приложение будет доступно по адресу `https://<user>.github.io/<repo>/`.
2. **Бот.** В @BotFather: `/newbot` → придумай имя и username.
3. **Кнопка открытия.** В @BotFather: `/mybots` → твой бот → *Bot Settings* → *Menu Button* → *Configure menu button* → вставь URL из шага 1 → название, например «Дневник».
   (Можно ещё `/newapp` — тогда будет ссылка вида `t.me/<bot>/<app>`.)
4. Открой бота и нажми кнопку меню. Старые записи: «Ещё» → «Импорт».

## Формат текста
```
[04.11.2026 21:00] Айбол: Среда
Жим лежа - 4х8 25кг
Жим лежа(30°) - 1х19 20кг 2х10 15кг
Жим гантелей сидя - 3х10 1x8 16кг     ← вес относится ко всем подходам перед ним
Махи в стороны - 12 15 15 10 6кг       ← разные повторы, один вес
Брусья - 4х20                          ← без веса
Гантели на бицепс - 2х12 9кг (читинг)  ← в скобках заметка
```
`х` можно писать и русской, и латинской буквой.

## Разработка
Без сборки: `index.html`, `style.css`, `parser.js`, `storage.js`, `app.js`.
Тесты: `node tests/parser.test.js` и `python3 tests/e2e.py` (Playwright, имитирует CloudStorage с лимитами Telegram).
